# 00-inbox/calls: atterraggio delle call

I transcript delle call arrivano qui (da soli, se attivi il modulo Granola; a mano altrimenti).
Il router li sposta in `<progetto>/knowledge/calls/` quando riconosce il progetto con certezza.

**Una call che resta qui è ambigua:** dimmi tu di quale progetto è, oppure aggiungi una parola
chiave al progetto in `.claude/config/brain.json`.

Nome del file: `AAAA-MM-GG-call-descrizione.md`.
