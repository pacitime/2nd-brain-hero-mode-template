# 10-lavoro: i progetti operativi

Un progetto = una cartella, sempre con la stessa anatomia (vedi `ARCHITETTURA.md` §3).

**Per aprire un progetto nuovo** chiedi a Claude: «crea il progetto <nome>». Copia
`_TEMPLATE-progetto/`, compila il README con te e aggiunge il progetto a
`.claude/config/brain.json` con le parole che lo fanno riconoscere.
