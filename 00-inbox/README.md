# 00-inbox: cattura rapida

Tutto ciò che non sai ancora dove mettere atterra qui: appunti, idee, documenti scaricati,
l'export della tua memoria da Claude. Poi chiedi a Claude «smista l'inbox»: sposta ogni cosa
al suo posto e ti chiede solo dove è in dubbio.

Un'idea resta qui come file singolo finché non è validata. Solo dopo diventa un progetto.
