# references/: gli essenziali, sempre caricati

> Pochi file piccoli che Claude deve avere davanti **ogni volta** che lavora su questo
> progetto: posizionamento, tono di voce, offerta e prezzi, fatti chiave, persone.
>
> Regola: se un file qui supera le due pagine, non è più un essenziale. Il dettaglio va nel
> `knowledge/wiki/`, qui resta la sintesi.

Entrano da soli quando nomini il progetto in chat, interi finché stanno nel tetto (circa
16.000 caratteri in tutto); oltre, l'assistente vede solo il nome del file e lo apre quando
serve. `metodo.md` ha un posto suo, con un tetto di 120 righe.

Esempi di file che hanno senso:
- `metodo.md`: come si lavora su questo progetto (c'è già, da riempire)
- `posizionamento.md`: a chi parli, quale problema risolvi, perché tu
- `tono-di-voce.md`: come scrivi, con due esempi veri
- `offerta.md`: cosa vendi, a quanto, con quali condizioni
- `brand.md`: colori, caratteri, regole visive
