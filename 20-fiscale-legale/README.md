# 20-fiscale-legale: società, contratti, contabilità

Il pilastro trasversale: serve tutti i progetti. Anatomia leggera (`ARCHITETTURA.md` §5):

- `documenti/`: contratti, visure, dichiarazioni, lettere
- `tasks/`: scadenze e cose da fare
- `calls/`: call con commercialista, avvocato, consulenti

Se hai più società, una sottocartella per ciascuna. Il legame con i progetti è una riga nel
README del progetto.

**Mai qui:** credenziali bancarie, codici di accesso, documenti d'identità.
